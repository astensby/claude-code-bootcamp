# ssb-private-cars-by-fuel.csv — registered private cars per Norwegian municipality, by fuel type, 2008–2025 (38 556 rows = 357 municipalities × 6 fuels × 18 years, offline snapshot; summed over SSB's "type of transport" dimension; "Other fuel" is mostly hybrids)
Source: Statistics Norway (SSB) table 07849 "Registered vehicles, by region, type of transport, type of fuel, contents and year" — https://www.ssb.no/en/statbank/table/07849 (API: https://data.ssb.no/api/v0/en/table/07849)
Fetched: 2026-09-27, revised 2026-09-28 — see FETCH.md for the exact query; this file is a static copy, do not call the API from exercises. Only the 357 municipalities (2024 codes) are in it: SSB's placeholder regions (`xx99` unknown-municipality rows, Svalbard, Jan Mayen, the continental shelf, county not stated) are dropped.
Columns: `municipality_code` (4-digit, 2024 codes) · `municipality` (name) · `county_code` (first two digits) · `county` (name) · `year` (2008–2025) · `fuel` (Petrol, Diesel, Paraffin, Gas, Electricity, Other fuel) · `private_cars` (count on 31 Dec)
Licence: Norwegian Licence for Open Government Data (NLOD) 2.0 — https://data.norge.no/nlod/en/2.0 — attribute "Statistics Norway".
