# brreg-employers-50plus.csv — every entity in the Norwegian Central Coordinating Register for Legal Entities (Enhetsregisteret) with 50 or more employees (8 038 rows, offline snapshot; sole proprietorships left out)
Source: Brønnøysundregistrene open API — https://data.brreg.no/enhetsregisteret/api/enheter (docs: https://data.brreg.no/enhetsregisteret/api/dokumentasjon/no/index.html)
Fetched: 2026-09-27 — see FETCH.md for the exact calls; this file is a static copy, do not call the API from exercises. The 20 sole proprietorships (`organisasjonsform` = ENK) are dropped: they are named after private individuals. 705 rows have no `stiftelsesdato`, 19 have no address municipality.
Columns: `organisasjonsnummer` (9-digit id) · `navn` (name) · `organisasjonsform` (AS, ORGL, KOMM, FLI, STI, …) · `naeringskode1` (NACE code) · `naeringskode1_beskrivelse` (NACE text, Norwegian) · `kommune` (business-address municipality) · `kommunenummer` (4-digit) · `fylke` (county, from the first two digits) · `stiftelsesdato` (founded, ISO date) · `antallAnsatte` (employees) · `registreringsdatoEnhetsregisteret` (registered, ISO date)
